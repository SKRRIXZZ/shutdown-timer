# ⏻ Таймер выключения ПК

Многоязычный таймер выключения / перезагрузки / сна / гибернации ПК с минималистичным плавающим виджетом и поддержкой трея.

[English](README.md) | **Русский**

---

## ✨ Возможности
- Выключение / Перезагрузка / Сон / Гибернация
- Отсчёт «через N времени» или «в конкретное время»
- Быстрые пресеты + свои пресеты
- Мини-виджет с режимом «сквозных кликов» для игр
- Глобальные хоткеи (`Ctrl+Alt+S` / `P` / `X`)
- 20 языков интерфейса
- Тёмная / светлая тема
- Автозапуск с Windows

---

## ✅ Требования
- Windows 10 или 11
- **Python 3.11 или новее** — нужен даже для `.exe` версии

---

## 🚀 Установка

### Шаг 1 — Установить / обновить Python (всегда, одна команда)

Открой **CMD** (`Win + R` → `cmd` → Enter):

```cmd
winget install --id Python.Python.3.12 -e --accept-source-agreements --accept-package-agreements & winget upgrade --id Python.Python.3.12 -e --accept-source-agreements --accept-package-agreements
```

Команда **поставит Python, если его нет**, и **обновит, если уже есть**.

Затем **закрой и снова открой CMD**, проверь:

```cmd
py -3 --version
```

### Шаг 2 — Обновить pip, setuptools, wheel (всегда, одна команда)

```cmd
py -3 -m pip install --upgrade pip setuptools wheel
```

## 📥 Установка приложения

### 🟢 A. Если у тебя `.exe` файл
Двойной клик по `ShutdownTimer.exe`. Готово.

### 🟡 B. Если у тебя `.pyw` файл
```cmd
py -3 -m pip install --upgrade pystray Pillow keyboard
pythonw shutdown_timer_multilang.pyw
```

### 🔴 C. Если у тебя `.bat`, который собирает `.exe`
```cmd
py -3 -m pip install --upgrade pyinstaller pystray Pillow keyboard
```
Затем двойной клик по `.bat`. Готовый `.exe` появится в `dist\`.

## ▶️ Использование
- Выбери действие: **Выключение / Перезагрузка / Сон / Гибернация**.
- Выбери режим: **через время** или **в конкретное время**.
- Выбери пресет или крути колёсики вручную.
- Нажми **▶ Запустить**. Главное окно скроется, появится мини-виджет.
- Кнопки мини-виджета: `⏸` пауза, `⤢` развернуть, `✕` отменить.

Хоткеи:
- `Ctrl + Alt + S` — показать / скрыть окно
- `Ctrl + Alt + P` — пауза / продолжить
- `Ctrl + Alt + X` — отмена

## 🛠 Проблемы

| Проблема | Решение |
|---|---|
| `'py' не является командой` | Переустанови Python с PrependPath (см. README погоды) |
| `pip` не найден | Используй `py -3 -m pip ...` |
| Гибернация не работает | Включи: `powercfg /hibernate on` в CMD от имени администратора |
| Хоткеи не работают | Их занял другой процесс; меню трея всё равно работает |
| Модуль `keyboard` требует прав | Правый клик по CMD → *Запуск от имени администратора* |
